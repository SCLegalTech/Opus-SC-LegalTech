# Roadmap

This roadmap is directional, not a promise of delivery dates.

## Public Self-Hosted Core

- Improve first-run setup.
- Add reproducible backend smoke scripts.
- Reduce backend cold-start time.
- Expand MCP tool coverage for safe self-hosted operations.
- Improve docs for provider credentials owned by the self-hoster.

## Community Contributions

- Documentation fixes.
- Small UI improvements.
- Tests and CI hardening.
- Generic integrations that do not depend on closed judicial operations.
- Adapter interfaces for community-maintained connectors.

## Hosted and Enterprise

- Maintained judicial last-mile connectors.
- Dedicated deployments.
- SSO and advanced audit controls.
- SLA-backed support.
- Custom integrations and compliance workflows.

Closed judicial connectors and SC LegalTech operational playbooks are not planned
for the fair-code self-hosted edition.
