# Support

Community support is best-effort through public GitHub issues and discussions
when enabled.

Please use public issues for:

- reproducible bugs in the self-hosted edition;
- documentation gaps;
- setup problems with sanitized logs;
- feature requests for the public core.

Do not use public issues for:

- secrets or vulnerabilities;
- private client data;
- production incidents;
- legal advice;
- requests for maintained judicial connectors;
- one-on-one implementation support.

Commercial support, hosted operations, enterprise deployment and maintained
judicial last-mile connectors are described in [COMMERCIAL.md](COMMERCIAL.md).
